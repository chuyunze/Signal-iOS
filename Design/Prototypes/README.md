# 私讯 UI 改版原型

本目录包含第一轮高保真视觉方向稿：

- `messages-home.png`：消息首页、置顶联系人、会话列表与底部导航。
- `private-chat.png`：一对一会话、媒体消息、语音消息与输入区。
- `profile-privacy.png`：个人资料、隐私中心与设置入口。

视觉方向：雾白背景、深墨文字、靛蓝主色、薄荷绿安全状态；强调留白、圆角、可读性和 iOS 原生交互习惯。

这些图片用于视觉讨论，并非逐像素实现规范。实现前应将颜色、字体、间距、圆角和阴影整理为统一的设计令牌。

## 第二轮：首页色调与布局备选

- `option-b-midnight-focus.png`：深色 OLED、紫青点缀、置顶卡片和紧凑会话面板。适合强调私密、高级和夜间使用。
- `option-c-warm-paper.png`：暖米白、森林绿与陶土橙，采用大卡片和编辑感排版。适合强调亲和、生活感。
- `option-d-nordic-air.png`：冰蓝白、钴蓝与青绿，采用筛选标签、紧凑列表和悬浮新建按钮。适合强调效率和现代感。

第二轮原型刻意不使用在线状态等新增服务端数据，可以基于现有客户端会话、置顶、未读数和筛选能力实现。

## 推荐主方案：隐光 / Luminous Quiet

- `luminous-home-light.png`：主页面日间版本。使用全部/未读/置顶筛选、紧凑置顶区、最近会话和浮动底部导航。
- `luminous-chat-light.png`：聊天页面。使用克制的渐变发送气泡、引用、图片、语音消息和浮动输入栏。
- `luminous-appearance.png`：客户端外观设置。包括晨雾、夜航、暖纸主题、界面密度、消息样式和聊天背景。
- `luminous-home-dark.png`：同一信息架构的原生深色版本，不是简单反色。

视觉签名是紫色到钴蓝、再到青色的“隐光”渐变。渐变只用于当前选中状态、未读数、发送消息和关键按钮，其余区域保持中性，从而兼顾辨识度、可读性与长期耐看性。

该方案只依赖当前 iOS 客户端已经具备的会话、置顶、未读筛选、聊天壁纸和本地主题能力；不要求服务端新增接口或字段。

## 首页收敛稿

- `luminous-home-compact.png`：根据最终反馈调整的高密度首页。移除“开始”建议卡片和通话标签；底部为消息、联系人、动态、我的；置顶会话使用普通紧凑行，一屏可显示约八条会话。
- `luminous-home-compact-dark.png`：与高密度首页完全一致的信息架构和内容，仅采用专门设计的夜间色板。

“我的”定义为重新设计后的设置首页。通话仍可从具体聊天或联系人详情发起，但不占用一级导航位置。

当前开发基线实现最终收敛稿，并复用 Signal 现有的“跟随系统 / 浅色 / 深色”主题切换。晨雾、夜航、暖纸等扩展主题仍属于后续视觉方向，不在本轮代码范围内。
